⛳ Golf Website

A modern, animated golf-themed website built with HTML, CSS, and GSAP. The project focuses on smooth animations, interactive elements, and a clean UI to give users a premium sports website experience.

🚀 Features

Smooth GSAP-powered animations for engaging UI

Responsive design (works across desktop, tablet, and mobile)

Interactive navigation with animated transitions

Golf-themed sections (home, about, events, contact, etc.)

Modern and minimal design with CSS styling

🛠️ Tech Stack

HTML5 – for structure

CSS3 – for styling and responsiveness

GSAP (GreenSock Animation Platform) – for animations

Clone this repository:

git clone https://github.com/Beachhousee/golf-website.git


Open the project folder.

Open index.html in your browser.

No extra setup is needed since it’s a static project.
